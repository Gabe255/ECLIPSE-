# ECLIPSE Brand Guide

ECLIPSE is the product identity and user-facing name of this repository. The brand should feel like a premium gaming space: atmospheric, focused, personal, and easy to navigate.

## Core idea

**ECLIPSE — Your Gaming Universe**

The visual metaphor is an eclipse: a dark, calm center surrounded by a precise halo of light. The mark combines a luminous crescent, an orbital path, and a small point of cyan light. It should remain recognizable at launcher-icon size.

## Color tokens

| Token | Hex | Use |
|---|---|---|
| Void | #100C19 | Main dark background |
| Deep plum | #171022 | Raised surfaces and depth |
| Lunar | #F3EEFF | Primary text and high-contrast details |
| Eclipse violet | #9B7BFF | Primary accent, focus, selected state |
| Soft violet | #C4B5FF | Secondary emphasis and highlights |
| Aurora cyan | #65D9E8 | Small contrast accent, active signal |
| Outline | #493B67 | Quiet borders and separators |

Color should communicate hierarchy, not decorate every surface. Reserve cyan for small highlights; violet is the primary interaction color.

## Shape and layout

- Prefer spacious, rounded surfaces with clear hierarchy.
- Use wide horizontal rows for game browsing and strong artwork when available.
- Keep focus states unmistakable for controller navigation.
- Avoid excessive glow, gradients, glass effects, and tiny labels.
- Keep motion short and purposeful; never make navigation feel slower for spectacle.
- Respect user-selected themes and accessibility settings. The ECLIPSE palette is the signature theme, not a reason to remove other themes.

## Logo use

- Use assets/branding/eclipse-mark.svg for the symbol.
- Use the ECLIPSE wordmark as live UI text where possible so it remains crisp at every density.
- Keep clear space around the mark; do not stretch, rotate, recolor arbitrarily, or place it on noisy artwork.
- The launcher icon uses the crescent/orbit mark on the Void background.
- Do not use NeoStation logos, names, badges, or upstream repository artwork as ECLIPSE branding.

## Voice

Write in a confident, concise, welcoming voice. Prefer product language such as Library, Systems, Entertainment, Collections, Settings, and ECLIPSE AI. Avoid references to upstream products in user-facing copy unless the context is an explicit credit, migration note, or compatibility explanation.

## Attribution

The codebase originated from the open-source NeoStation project and includes inherited components. Preserve required upstream and third-party notices and license obligations. Attribution belongs in project credits and legal notices, not in the ECLIPSE logo, launcher, or primary interface.
